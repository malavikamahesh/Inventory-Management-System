# Inventory-Management-System# Inventory Management System

## Overview

The Inventory Management System is a web-based application developed using HTML, CSS, JavaScript, LocalStorage, and Chart.js. It enables users to manage inventory efficiently by performing CRUD operations on products, tracking stock levels, and visualizing inventory statistics through an interactive dashboard.

The application consists of two main modules:

* Product Management
* Inventory Dashboard

---

## Features

### Product Management

* Add new products
* Edit existing products
* Delete products
* Search products by name or category
* Sort products by quantity
* Sort products by price
* Highlight low-stock items
* Form validation
* Data persistence using LocalStorage

### Inventory Dashboard

* Total Products
* Total Stock Quantity
* Total Inventory Value
* Low Stock Product Count
* Most Stocked Category
* Category-wise Breakdown Chart
* Product Quantity Bar Chart
* Real-time analytics from stored inventory data

### Additional Features

* Responsive Design
* Dark Theme UI
* Home Page Navigation
* Dynamic Dashboard Updates
* Modern Dashboard Layout
